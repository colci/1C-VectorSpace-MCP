## Инструкция по запуску всей конфигурации

### Шаг 1. Полная выгрузка конфигурации из 1С
Если вы хотите обновить файлы конфигурации, запустите скрипт:
```powershell
powershell -File .\export_config.ps1
```

### Шаг 2. Запуск полной индексации
Убедитесь, что в файле `.env` указан путь к полному каталогу выгрузки (`EXPORT_PATH=D:\Export\UNF`), и выполните индексатор:
```powershell
.venv\Scripts\python.exe index_config.py
```
*Скрипт проиндексирует всю конфигурацию. При использовании локального FastEmbed это займет некоторое время в зависимости от объема файлов.*

**Частичная/Тестовая индексация:**
Если вы хотите проиндексировать только определенный модуль или папку для проверки, используйте переменную окружения `INDEX_FILTER`:
* В PowerShell:
  ```powershell
  $env:INDEX_FILTER="RFIDКлиент"; .venv\Scripts\python.exe index_config.py
  ```
* В CMD:
  ```cmd
  set INDEX_FILTER=RFIDКлиент && .venv\Scripts\python.exe index_config.py
  ```
* В Python / Bash:
  ```bash
  INDEX_FILTER="RFIDКлиент" .venv/Scripts/python index_config.py
  ```


### Шаг 3. Запуск MCP-сервера в вашей среде разработки
Вы можете запустить MCP-сервер локально через:
```powershell
.venv\Scripts\python.exe mcp_server.py
```

Для подключения его к вашему IDE-клиенту (например, Claude Desktop или другому ассистенту), добавьте следующую конфигурацию в настройки MCP:

```json
{
  "mcpServers": {
    "1c-assistant": {
      "command": "D:\\work\\Test2\\.venv\\Scripts\\python.exe",
      "args": [
        "D:\\work\\Test2\\mcp_server.py"
      ],
      "env": {
        "NO_PROXY": "localhost,127.0.0.1",
        "EXPORT_PATH": "D:\\Export\\UNF",
        "QDRANT_URL": "http://localhost:6333"
      }
    }
  }
}
```
*(При необходимости добавьте переменную `OPENAI_API_KEY`, если решите переключиться на облачные эмбеддинги OpenAI).*
