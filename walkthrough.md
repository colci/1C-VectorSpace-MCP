## Что было сделано

### Этап 1. Базовая реализация
1.  **Скрипт выгрузки 1С:** Создан PowerShell-скрипт [export_config.ps1](file:///d:/work/Test2/export_config.ps1) для инкрементальной выгрузки BSL и XML файлов с использованием утилиты `ibcmd --sync`.
2.  **Скрипт индексации:** Создан Python-скрипт [index_config.py](file:///d:/work/Test2/index_config.py), который парсит программные модули на отдельные процедуры/функции (BSL-чанги) и генерирует структурированные карточки из XML-файлов метаданных, после чего локально вычисляет эмбеддинги (через FastEmbed) и загружает их в Qdrant.
3.  **MCP-сервер:** Создан файл [mcp_server.py](file:///d:/work/Test2/mcp_server.py) на базе FastMCP, предоставляющий ИИ-модели инструменты `search_code`, `search_metadata`, и `get_file_snippet`.

### Этап 2. Оптимизация памяти и защита от зависаний (Текущий)
1.  **Мониторинг RAM:** Добавлена библиотека `psutil` в зависимости [requirements.txt](file:///d:/work/Test2/requirements.txt) для динамического отслеживания загрузки оперативной памяти.
2.  **Контроль лимитов (Throttling):** В [index_config.py](file:///d:/work/Test2/index_config.py) внедрен метод `check_memory_limit()`. Перед запуском тяжелых операций генерации векторов он проверяет уровень загрузки RAM:
    *   При превышении лимита (по умолчанию `70%`) скрипт принудительно запускает сборщик мусора `gc.collect()` и засыпает на 5 секунд.
    *   Если после 30 секунд ожидания память не освобождается, выводится предупреждение, и процесс продолжается с осторожностью.
    *   При критическом превышении памяти (>85%) индексатор становится на жесткую паузу до тех пор, пока память не освободится другими процессами, предотвращая падение системы (Out of Memory).
3.  **Ограничение CPU-потоков:** Значение потоков FastEmbed по умолчанию теперь ограничено до `2` (или жестко настраивается через `.env` переменной `FASTEMBED_THREADS=2`), что исключает загрузку процессора на 100% и зависания ОС.
4.  **Плавная индексация (Sub-batching):** 
    *   Размер батча чанков по умолчанию снижен с `1000` до `100` (`INDEX_BATCH_SIZE`).
    *   При передаче данных в FastEmbed ONNX Runtime теперь обрабатывает тексты мелкими частями по `32` элемента (`batch_size=32`), что существенно снижает пиковое потребление памяти.
### Этап 3. Визуализация прогресса и оптимизация отправки векторов (Текущий)
1.  **Предварительная детекция изменений**:
    *   Скрипт быстро проверяет список файлов на диске против кэша.
    *   Если файлы не менялись, скрипт завершает работу мгновенно, не занимая ресурсы.
    *   Если изменения обнаружены, выводится точное число файлов для индексации.
2.  **Защита вывода (tqdm.write)**:
    *   Внедрен `pbar.write` для вывода логов батчей поверх прогресс-бара, предотвращая дублирование и поломку строк в PowerShell.
3.  **Интерактивный прогресс вычислений**:
    *   Для локальной модели FastEmbed добавлен временный вложенный прогресс-бар `├ Вычисление векторов`, отражающий прогресс вычисления эмбеддингов для текущего батча на процессоре.
4.  **Групповая отправка в OpenAI**:
    *   Переписана отправка запросов к API OpenAI: теперь эмбеддинги для всего батча генерируются за один сетевой запрос `openai_client.embeddings.create(input=docs)` вместо 100 последовательных запросов.

## Инструкция по запуску всей конфигурации

### Шаг 1. Полная выгрузка конфигурации из 1С
```powershell
powershell -File .\export_config.ps1
```

### Шаг 2. Запуск индексации
Убедитесь, что в `.env` настроены лимиты:
```ini
INDEX_BATCH_SIZE=100
FASTEMBED_THREADS=2
MAX_RAM_PERCENT=70
```
Запустите индексатор:
```powershell
.venv\Scripts\python.exe index_config.py
```

### Шаг 3. Запуск MCP-сервера
Добавьте следующую конфигурацию в настройки вашего ИИ-ассистента:
```json
{
  "mcpServers": {
    "1c-vectorspace-mcp": {
      "command": "D:\\work\\Test2\\.venv\\Scripts\\python.exe",
      "args": [
        "D:\\work\\Test2\\mcp_server.py"
      ],
      "env": {
        "NO_PROXY": "localhost,127.0.0.1",
        "EXPORT_PATH": "D:\\Export\\1C",
        "CONFIG_NAME": "MyConfiguration",
        "CONFIG_ID": "my_configuration",
        "CONFIG_PROFILE": "generic",
        "QDRANT_URL": "http://localhost:6333"
      }
    }
  }
}
```
